# CA-1: Data Analysis & Visualization (Airbnb Dataset)

This assignment focuses on **exploratory data analysis and visualization** using real-world Airbnb data.
The goal is to extract meaningful insights from the dataset through data cleaning, statistical analysis,
and visual exploration, and to present the results in a clear and interpretable way.

---

## What This Project Does

In this project, We analyzed Airbnb listing data to understand pricing patterns, neighborhood effects,
and other relevant features.
The work emphasizes **data exploration, visualization, and interpretation**, rather than predictive modeling.
